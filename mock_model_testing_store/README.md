# mock_model_testing_store

Песочница для проверки модели в браузере. Свои тестовые данные (не из csv) выгружаются в store,
который имитирует localStorage; сервис `getPlan()` берёт их оттуда и считает.
Не часть продукта: нужна только для разработки, в корневой package.json ничего не меняет.

## Запуск
```bash
cd mock_model_testing_store
npm install
npm start
```
Открыть http://localhost:5199. После правок кода: остановить (Ctrl+C) и снова `npm start`
(перед сборкой автоматически копируется свежий код модуля и .onnx из корня проекта).

Почему не `vite dev`: пока корневой `package.json` пуст, dev-сервер Vite падает при чтении JSON;
сборка и preview работают.

1. Выберите пресет (или правьте поля вручную) и предшественника.
2. «Выгрузить в store» - данные попадут в блок «Store».
3. «Посчитать» - модель + матрица + план на 3 года. Повторное нажатие берёт ответ из store.

Свои данные: правьте `PRESETS` в `src/mockStore.js`.
